# UAS Data Mining - Prediksi Risiko Diabetes & Clustering Lokasi Gerai Kopi

Aplikasi web interaktif berbasis **Streamlit** untuk memenuhi tugas Ujian Akhir Semester (UAS) mata kuliah Data Mining.

## Fitur Utama:
1. **Klasifikasi Risiko Diabetes**: Memprediksi status diabetes pasien menggunakan algoritma *K-Nearest Neighbors (KNN)*, *Naïve Bayes*, dan *Decision Tree* (lengkap dengan metrik evaluasi dan Confusion Matrix).
2. **Clustering Lokasi Gerai Kopi**: Mengelompokkan titik lokasi gerai kopi menggunakan algoritma *K-Means* untuk mendeteksi persebaran serta zona dengan potensi kepadatan rendah (zona sepi).
